# FounderSprint 관리자(Admin) 매뉴얼

> 이 문서는 FounderSprint에서 **관리자(Admin) 또는 최고 관리자(Super Admin)** 역할로 프로그램을 운영하는 분을 위한 안내서입니다.

---

## 1. FounderSprint란?

FounderSprint는 **기수(Batch) 단위로 창업 프로그램을 운영**하는 시스템입니다.
관리자는 기수를 만들고, 사람을 초대하고, 과제·세션·이벤트를 관리합니다.

핵심 용어:
- **기수(Batch)** = 프로그램 한 기수 (예: Founder Sprint Batch 6)
- **과제(Assignment)** = 참여자가 제출해야 하는 일
- **세션(Session)** = 프로그램 일정 (강의, 점검 등)
- **이벤트(Event)** = 별도 행사 (온라인/오프라인)
- **오피스아워(Office Hours)** = 멘토-창업자 상담 시간

대부분의 화면은 **현재 선택된 기수**를 기준으로 보여집니다.

---

## 2. 역할 구분

| 역할 | 무엇을 할 수 있나요? | 무엇이 안 되나요? |
|------|---------------------|------------------|
| **최고 관리자 (Super Admin)** | 모든 것 + Super Admin 권한 부여 | 없음 |
| **관리자 (Admin)** | 기수/사용자/과제/세션/이벤트 관리, 초대 | Super Admin 지정 불가 |
| **멘토 (Mentor)** | 과제 생성, 질문 답변, 오피스아워 운영 | 기수/사용자 관리 불가 |
| **창업자 (Founder)** | 과제 제출, 질문, 오피스아워 요청 | 운영 권한 없음 |
| **공동창업자 (Co-founder)** | Founder와 동일 | 초대 시 Founder 연결 필요 |

---

## 3. 기수 만들기

### 새로 만들기
1. **Admin → Batches**로 이동
2. **Create Batch** 클릭
3. 기수 이름, 시작일, 종료일 입력
4. 저장

### 기존 기수 복제하기
이전 기수의 과제/세션 구조를 그대로 가져오고 싶을 때 사용합니다.

1. **Admin → Batches**에서 원본 기수의 **Clone Structure** 클릭
2. 새 기수 이름과 기간 입력
3. **Clone Batch** 클릭

**복제되는 것:**
- 과제 구조
- 세션 구조

**복제 안 되는 것:**
- 참여자 목록
- 이벤트
- 오피스아워
- Google Calendar / Meet 링크
- 회사별 대상 설정

즉, **"운영 틀"만 복사되고, 사람과 외부 연동은 새로 잡아야 합니다.**

### 복제 직후
안내 창이 뜹니다:
- **Invite Members Now** → 바로 사람 초대로 이동
- **Review Batch First** → 새 기수 설정 먼저 확인
- **Close** → 닫기

---

## 4. 사람 초대하기

### 한 명씩 초대
1. **Admin → Users**에서 기수 선택
2. **Invite User** 클릭
3. 이메일, 이름, 역할 입력
4. Co-founder의 경우 연결할 Founder 선택
5. 저장

### 여러 명 한 번에 초대
1. **Admin → Users**에서 기수 선택
2. 초대 창 → **Bulk** 모드 선택
3. 이메일 목록 붙여넣기
4. 역할 선택 후 저장

### 복제 후 바로 초대
**Invite Members Now**를 누르면:
- 새 기수가 선택된 상태로 초대 창이 열립니다
- 원본 기수의 멤버가 목록으로 미리 표시됩니다
- **모두 체크 해제된 상태**이므로, 원하는 사람만 골라서 초대하면 됩니다

### 초대 결과
- **Invited** = 정상 처리된 수
- **Skipped** = 건너뛴 수 (이미 있거나 회사 충돌 등)

### 알아둘 점
- 완전히 새로운 사용자는 **초대 이메일**을 받습니다
- 이미 시스템에 있는 사용자는 **이메일 없이 바로 추가**될 수 있습니다

---

## 5. 초대 수락 후 일어나는 일

### 흐름
1. 사용자가 초대 이메일의 링크를 클릭
2. 로그인
3. 해당 기수 멤버로 활성화
4. **시작 안내 메일(온보딩 메일)** 발송 가능

### 시작 안내 메일에 포함되는 링크
- Assignments (과제)
- Sessions (세션)
- Events (이벤트)

포함되지 않는 것:
- Office Hours (별도 안내 필요)

### 링크 동작
메일의 링크를 누르면 **해당 기수가 자동으로 선택된 상태**로 화면이 열립니다.

---

## 6. 과제 관리

### 할 수 있는 일
- 과제 만들기
- 제출물 확인
- 피드백 작성
- 미제출자 확인
- 과제를 **템플릿으로 저장**해서 나중에 재사용

### 과제 템플릿
- 과제를 만든 뒤 **Save as template**로 저장 가능
- 새 과제 만들 때 **Start from template**에서 선택하면 자동 채움
- 불필요한 템플릿은 **Delete** 가능
- 기존 과제에는 영향 없음

### 24시간 전 자동 리마인더
- 시스템이 **매일 KST 오전 10시**에 검사
- 마감 약 24시간 전 과제의 **미제출자**에게 리마인더 발송
- 같은 사람에게 중복 발송하지 않음

---

## 7. 세션과 이벤트

### 세션(Session)
프로그램 일정입니다. 예: 강의, 점검 미팅
- 기수에 속합니다
- 회사 단위로 대상을 제한할 수 있습니다
- Google Calendar 일정으로 동기화 가능

### 이벤트(Event)
별도 행사입니다. 예: 데모데이, 네트워킹, 온라인 세미나
- **Virtual** / **Office Hour** 유형은 **Google Meet 링크**가 자동 생성됩니다
- **In-person** / **General Session** 유형은 Meet 없이 일정만 생성됩니다
- 회사 단위 대상 제한 가능 (배치 1개 선택 시에만)
- 여러 배치에 동시 노출 가능

### 세션 vs 이벤트 핵심 차이
- **Session** = 일정 중심, Meet 자동 생성 아님
- **Virtual Event** = Meet 링크까지 포함되는 온라인 행사

### 복제된 기수에서 주의
복제된 세션은 **기존 Google Calendar / Meet 링크를 가져오지 않습니다.**
구조만 복사되므로, 외부 연동은 새로 설정해야 합니다.

---

## 8. 이벤트 배치 범위 설정

이벤트를 만들 때 **어떤 기수에 보이게 할지** 선택할 수 있습니다.

| 선택 | 의미 | 회사 지정 가능? |
|------|------|---------------|
| **All Batches** | 현재 활성 기수 전체에 노출 | 불가 |
| **Specific Batches** (1개) | 해당 기수에만 노출 | **가능** |
| **Specific Batches** (2개 이상) | 선택한 기수에만 노출 | 불가 |

즉, **회사 단위 대상 제한은 배치를 하나만 선택했을 때만 가능**합니다.

---

## 9. 오피스아워

오피스아워는 별도 관리 기능입니다.
- 멘토가 시간을 열고, 창업자가 요청하는 구조
- 기수 복제 시 자동으로 넘어가지 않음
- 시작 안내 메일에도 현재 포함되지 않음
- **별도로 설정하고 안내해야 합니다**

---

## 10. 설정과 기수 전환

### Settings
프로필과 기본 설정을 관리하는 화면입니다.

### 기수 전환 (Batch Switcher)
여러 기수에 속한 사용자는 **batch switcher**로 현재 기수를 바꿀 수 있습니다.
바꾸면 보이는 과제, 세션, 이벤트가 달라집니다.

---

## 11. 운영 시 꼭 알아둘 점

### 1) 복제는 구조만 복사합니다
사람, 이벤트, Meet 링크는 복사되지 않습니다.

### 2) Gmail/Calendar 성공 ≠ 받는 사람에게 보임
- 메일 전송 성공이 반드시 받은편지함 도착을 뜻하지는 않습니다
- Calendar 생성 성공이 받는 사람 캘린더에 자동으로 뜬다는 보장은 아닙니다

### 3) 기존 사용자와 신규 사용자 처리가 다릅니다
- 신규 → 초대 메일
- 기존 → 바로 추가될 수 있음

### 4) Session과 Virtual Event는 다릅니다
- Session = 일정 중심 (Meet 자동 생성 아님)
- Virtual Event = Meet 링크 포함 온라인 행사

---

## 12. 권장 운영 순서

### 새 기수
1. 기수 생성
2. 사용자 초대
3. 과제 / 세션 / 이벤트 확인
4. 필요한 안내 발송

### 기수 복제
1. Clone Structure
2. 과제/세션 확인
3. 사람 초대 (즉시 또는 검토 후)
4. 회사/대상 설정 재확인
5. 외부 연동(Calendar/Meet) 점검

---

## 13. 문제 해결

### "사용자가 기수를 못 봅니다"
- active 상태인지 확인
- 해당 기수에 실제로 추가돼 있는지 확인
- 현재 선택 기수가 맞는지 확인

### "초대 메일이 안 간 것 같습니다"
- 기존 사용자라서 바로 추가된 건 아닌지 확인
- Gmail 설정 확인
- 초대 링크 생성 여부 확인

### "Session/Event은 있는데 Meet 링크가 없습니다"
- Event 유형이 Virtual / Office Hour인지 확인
- Google Calendar 설정 확인
- 복제된 항목인지 확인 (복제 시 Meet 복사 안 됨)

### "리마인더가 발송되지 않습니다"
- 과제가 24시간 전 범위에 들어왔는지 확인
- 이미 제출한 사람은 아닌지 확인
- 이전에 이미 발송된 기록이 있는지 확인
